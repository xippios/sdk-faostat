directory are written by `scripts/refresh_upstream.py` (`/refresh-upstream`) from the
pages in the table below and refreshed deliberately by PR, so that changes show up as
diffs. This file is generated by the same script; nothing here is edited by hand but
`OBSERVED.md`, where it exists: what upstream does but never documents, each note with
its evidence.

## How this is captured

FAO documents the FAOSTAT API in an OpenAPI document, kept verbatim as
`openapi/faostat_openapi.yaml` from
https://www.fao.org/faostat/en/docs/faostat_openapi.yaml (`SPEC_URL`), and renders it on
the ReDoc page https://www.fao.org/faostat/en/docs/redoc-static.html. No page links the
document: it is served beside the ReDoc page, which embeds a copy of its own and draws
it in the browser. The script checks on every run that the copy holds no text the
document lacks but a development server, and that the page's text is the copy's and
ReDoc's labels; the page is a row without a file. The document is YAML, so the script
reads its `info` itself: it names no licence, terms of service or contact.

The developer portal, https://www.fao.org/faostat/en/#developer-portal, is a fragment of
https://www.fao.org/faostat/en/, the portal's application shell, an empty page that a
RequireJS application fills in the browser; it carries no documentation text and is a
row without a file.

The FAO Statistical Database Terms of Use are converted to Markdown with the standard
library's `html.parser`: the page's content, its headings, paragraphs, lists, tables and
links (made absolute) kept, a table with merged cells or a nested table kept as HTML,
the site's header, navigation, breadcrumb, share buttons, footer and scripts dropped.
The run stops on an element the converter does not know. The page is the terms
themselves: every run checks that it prints each statement under Attribution, and the
file's diff shows any other change.

The bulk downloads' catalogue is open and kept verbatim; its description of the census
dataset WCAD says census reports are “available in the public domain”, which states
nothing about the catalogue, so the check reads past the phrase. The four samples under
`samples/` are answers of the API, kept verbatim, sent through the package's own client:
its login, `auth_login` (`POST /auth/login`, the form fields `username` and `password`),
runs once, inside the client's auth flow, before the first sample. A sample refused with
HTTP 401 or 403 logs in once more and is sent again, once, inside that flow: no retry of
the capture's own, which sends each sample once, and counted among its requests, as the
login is. Their `metadata.processing_time` changes on every request, which `--check`
disregards. They are structural samples; test fixtures are recorded separately.

Fetched is the UTC time the run started, in ISO 8601 with an explicit Z, the same for
every row. Bytes and sha256 are those of the body as fetched: a converted page's row
holds the HTML page's, an excerpt's the whole document's, a file split from a page the
page's. Last-Modified is the HTTP header in UTC, or as sent in a code span where it is
no HTTP date, and ETag is as sent, in a code span, on a row that ends in a comment
telling the secret scan it is no key. A page recorded without a file is `(no file)`, and
a body that changes on every request records no size, sha256 or ETag. A sample is a
small answer of the API kept verbatim under `samples/`, which documents the answer's
shape and is no test fixture. Requests go one at a time, 2 s apart, through core's
client, each retried at most once and no sooner than 10 s, a 429 after the wait the
client gives it where that is longer, and are identified as `xippios-faostat/<version>
(+https://github.com/xippios)`, the source package's version in place of `<version>`. No
redirect to another host is followed and no browser is imitated. Only the keyed samples
send a credential, the one the source's client reads from `FAOSTAT_USERNAME` and
`FAOSTAT_PASSWORD`, to its base URL's origin alone; they follow no redirect and are
never retried, and neither a credential nor a token is written. A page an anonymous
client cannot read is requested once and listed under Not fetched.
